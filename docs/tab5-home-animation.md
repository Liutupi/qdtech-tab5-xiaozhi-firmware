# TAB5 主页 NABO 动画

本轮扩展原生主页的动作与互动。立绘、眼睛、嘴型与睡姿继续使用原素材，新增按 NABO 形象生成的分层挥手及 8 种反应。原始素材保持完整，图片与生成提示词见 `assets/nabo/`。

## 行为

- 待机：缓慢的呼吸光点与错开的自然眨眼。
- 聆听：进入时短眨眼，现有 VAD 检测控制小波形强弱。
- 思考：连接期间和收到非空用户 STT 文本后，半眯眼与三点等待反馈；收到新设备状态时退出。它是显示层状态，不改变 Application 状态机。
- 说话：三种现有嘴型按多段节奏切换；播放队列与解码/输出任务全部空闲时闭口。不是音素识别或严格口型同步。
- 挥手：固定身体和单独前臂，角度连续变化，20 ms 采样，1.6 秒结束；语音交互优先，说话时使用原有口型。
- 触摸：短按轮换挥手、眨眼、点赞和好奇；两次短按间隔小于 400 ms 时显示开心。长按继续进入感应测试。
- 反应：倾听、思考和支持的情绪消息触发相应的短暂姿势；待机每 18–25 秒显示轻量反应，播放音乐时使用听歌姿势。
- 休息：睡眠 z 符号平滑漂移。预览与休眠期间停止脸部更新，退出后恢复小块图层。

## 成本和调度

通常 LVGL UI 定时器为 40 ms；挥手期间 UI/刷新定时器为 20 ms，结束和打断时恢复。实际帧率由硬件负载决定。其他应用轮询保持约 50 ms 节奏，无补帧循环。眨眼、嘴型根据 LVGL 毫秒时钟推进；新增姿势使用 ESP 的 64 位单调毫秒时钟，忙帧不会拉长一次性动作。脸部控制器固定大小不超过 64 字节，姿势控制器只保存动作及开始时间，无动态分配、文件 IO 或音频处理。眼睛仍仅更新 312×125 区域，嘴巴 48×31，波形高度未改变时不更新控件。未加入整幅立绘的呼吸缩放、平移或淡入淡出，以控制大面积透明重绘成本。

## 连续挥手 v3

替换独立立绘跳图为固定身体和连续前臂轨迹，视频 50 fps。当前构建和检查见 `assets/nabo/validation-v3.md`；本轮没有刷机。


## 挥手比例修正 v4（2026-10-01）

v3 把完整袖口误当成肘部，多叠了一段前臂。v4 使用短手腕和手掌，以 ±8° 小幅旋转；固定身体、手掌、袖口前缘依次绘制。运行时手掌 74 × 78 RGB565A8，预览与固件采用同一控制器。详见 `assets/nabo/validation-v4.md`。已通过原生固件编译，尚未刷机。


## 协调挥手 v5（2026-10-01）

v4 只有手掌在动。v5 将同一素材注册为脚、上身、头、手与袖口前缘，髋部运动带动肩膀和手腕，头部稍晚倾动与小幅点头，脚保持落地。动作 2.4 秒，原生 UI 与导出预览共用 C++ 时间轴和变换。已编译，尚未刷机；整体绘制面积增大，需要实测显示与音频并行性能。详见 `assets/nabo/validation-v5.md`。


## NABO 连续反应 v6

保留 v5 挥手，新增开心、思考、聆听与音乐的连续动作。每组 1.8 秒，原生 UI 在动作期间目标 20 ms 更新；眨眼、鼓励、好奇、安慰仍是静态姿势。思考的头、托腮手和上身作为一层移动，其他三种保留小幅头部跟随。触发、资产生成方式、构建大小与真机限制见 `assets/nabo/README.md` 和 `assets/nabo/validation-v6.md`。本轮尚未刷机。


## NABO 全部互动动作 v7

眨眼、鼓励、好奇和安慰补成连续动作，保留 v5 挥手与 v6 四组。现有触摸和对话状态继续调用这些动作；回复情绪改为单槽等待，在说话/播放排空后、用户安静时展示最近一次。空闲轮换好奇/思考/眨眼，音乐开始或恢复后在主页可用时展示音乐动作。新问题、触摸、休眠、预览和页面切换清掉旧的待显示情绪。完整事件表及验证见 `assets/nabo/README.md`、`assets/nabo/validation-v7.md`。尚未刷机。
