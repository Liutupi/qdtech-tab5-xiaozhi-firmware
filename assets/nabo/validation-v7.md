# NABO 全部互动动作 v7 验证记录

## 已实现

沿用 v5 挥手、v6 开心/思考/聆听/音乐。原来四张静态反应现已加入连续动作，每组 1.8 秒：

- 眨眼：俏皮表情、身体侧倾和小幅手腕回应。单眼闭合表情沿用原图；动作结束回到睁眼主立绘。未新增独立眼皮开合帧。
- 鼓励：原图点赞、上身点动、小幅手腕配合。
- 好奇：保持原来的歪头形象，左右探身。
- 安慰：双手抱心与轻缓上身呼吸/点动。

保持相同角色与人体比例。手掌、前臂均来自原素材，手腕在源坐标注册，袖口前缘遮挡连接处；不添加新的手臂长度。四个新姿势的头与上身保留在同层，避免面部切层细线。素材注册为 `source/reactions-rig-v7.json`，保留旧 v6 源注册。全部 C/H 由 `scripts/prepare_nabo_assets.py` 生成。新增十二张 PNG 图层。

## 使用方式

- 相机确认有人进入时沿用挥手。轻触角色轮换挥手、眨眼、鼓励、好奇；400 ms 内双击开心；长按沿用测试感应。
- 开始聆听选聆听动作，识别到用户问题选思考。服务器回复的情绪标签决定开心、眨眼、好奇、鼓励或安慰；本轮未增加本地文本情绪识别。
- 清醒空闲时每 18–25 秒轮换好奇、思考、眨眼。音乐开始/恢复后将下次空闲动作设为就绪，主页可显示时选音乐，随后仍按空闲间隔显示。应用页面打开期间不绘制这些动作。
- 说话时保留原口型。用一个有界待显示槽保留最近的回复情绪，新的标签覆盖旧的。neutral 状态更新不清除它；TTS 或音频播放队列未排空时暂停过期计时，长回复也能在结尾展示最近一次情绪。
- 队列排空、没有用户语音、没有正在等待回复、当前姿势已结束时，在倾听/空闲间隙展示待显示动作。语音之外等待 15 秒未能显示则过期。
- 新的用户语音恢复聆听并清掉旧的待显示情绪；识别到新问题、触摸、休眠、相机预览和应用页面切换同样清掉旧槽。没有扩大协议、音频或 Application 状态契约。
