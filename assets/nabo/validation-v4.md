# NABO 手腕挥动 v4 验证记录

日期：2026-10-01。对应用户反馈：上一版手臂不自然、多了一截。

## 原因和修复

v3 的固定身体已经有完整白色袖子，移动图层却又带一整段白色前臂。我把袖口误当成肘部，造成重复延长。v4 保留原身体与袖子，使用内置图像生成工具编辑出只有手掌、五指和短手腕的透明图层。生成来源与完整提示词保存在 `source/animation-v4-prompt.md`；注册参数在 `source/wave-hand-v4.json`。

绘制顺序：固定身体（含袖口后缘）、活动手掌、固定袖口前缘。前缘取自同一身体图片，用注册多边形生成小遮挡层。原来的袖口灰色内部不再盖住整只手腕。手掌静止倾角 -20°，在此基础上围绕手腕 ±8° 摆动；动作 1.6 秒。固件和预览使用同一控制器及遮挡顺序。两份项目目录均已同步本次修复；不同版本的显示头文件分别修改，未相互覆盖。
